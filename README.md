# ماهذا؟

صفحة لتعلّم أسماء الأشياء بالإنجليزية. تعمل الكاميرا بملء الشاشة، ويحلّل نموذج COCO‑SSD لقطة داخل إطار التصويب عند الضغط على «ماهذا؟». يفحص النموذج فئاته الثمانين، ويعرض الاسم وينطق جملة قصيرة بصوت المتصفح. زر الصوت يعيد نطق الكلمة. الصور لا تُرسل أو تُحفظ.

## على الكمبيوتر

شغّل Start.cmd بنقرتين من المجلد، أو افتح المجلد في VS Code وشغّل في الطرفية:

```powershell
python -m http.server 3000 --bind 127.0.0.1
```

افتح [معاينة الكمبيوتر](http://localhost:3000) واضغط «شغّل الكاميرا». أبقِ الطرفية مفتوحة أثناء التجربة.

## على الجوال

1. افتح تبويب **Ports** في VS Code واختر **Forward a Port** ثم أدخل `3000`.
2. تأكد من أن **Port Visibility** على **Private**. انسخ عنوان **Forwarded Address** الذي يبدأ بـ HTTPS.
3. افتح الرابط في Safari أو Chrome على الجوال وسجّل دخولك بنفس حساب GitHub المستخدم في VS Code.
4. اسمح بالكاميرا، وضع غرضًا مدعومًا في وسط الإطار واضغط «ماهذا؟». عند الانتهاء أوقف مشاركة البورت وأغلق الطرفية.

[دليل فتح البورت الخاص في VS Code](https://code.visualstudio.com/docs/debugtest/port-forwarding)

تفتح الكاميرا مباشرة بعد الإذن. أول ضغطة على «ماهذا؟» تحمّل نموذج الوضع المختار، وقد تحتاج وقتًا لأن ملفات النموذج تُقرأ عبر رابط الصفحة. بعدها تتم معالجة اللقطة على الجهاز الذي فتح الصفحة. النطق يعتمد على أصوات المتصفح. إذا طلب المتصفح لمسة لتشغيل الصوت، اضغط زر الصوت بجانب الكلمة.

## مكونات التعرّف

- [TensorFlow.js 4.22.0](https://github.com/tensorflow/tfjs/tree/tfjs-v4.22.0)
- [COCO‑SSD 2.2.3 وقائمة الفئات](https://github.com/tensorflow/tfjs-models/tree/master/coco-ssd)

## التعرّف الموسّع

اختر «تعرّف موسّع» ثم اضغط «ماهذا؟». يحتاج أول تحميل لهذا الوضع نحو 13.7 ميغابايت على دفعات لا تتجاوز نصف ميغابايت. يظهر تقدّم التحميل وتُحفظ الملفات المكتملة في المتصفح للمرات التالية ما دامت مساحة التخزين متاحة. يعالج MobileCLIP‑S0 اللقطة داخل المتصفح ويقارنها بقائمة من 1000 كلمة مختارة للأطفال من 4 إلى 11 سنة، مقسّمة على ثلاثة مستويات (4–6، 7–9، 10–11). التعرّف قد يخطئ، وإذا لم يكن واثقًا يطلب تقريب الغرض بدل التخمين. زر «تعرّف أساسي» يلغي التحميل الموسّع إن كان جاريًا ويرجع إلى COCO‑SSD، مع بقاء الكاميرا مفتوحة.

المشروع هنا للتجربة التعليمية المحلية. أوزان MobileCLIP وإصدارها المحوّل متاحة وفق ترخيص Apple للأبحاث، والمرفق داخل vendor/expanded-lite. تستخدم هذه النسخة أوزانًا مضغوطة بدقة 8 بت وفهرس كلمات بدقة 8 بت.

Apple Machine Learning Research Model is licensed under the Apple Machine Learning Research Model License Agreement.

النسخة الموجودة في vendor/expanded-lite نموذج مشتق (Model Derivative) من MobileCLIP‑S0. التعديلات: تحويل أوزان مُشفّر الصور إلى دقة 8 بت (int8)، وضغط الملفات بـ gzip وتقسيمها إلى أجزاء لا تتجاوز نصف ميغابايت. فهرس الكلمات ناتج من مُشفّر النصوص في النموذج (متوسط عشر صيغ وصفية لكل كلمة)، ومحفوظ بدقة 8 بت. لم يُعَد تدريب النموذج ولم تتغير بنيته. هذا المشروع غير مرتبط بـ Apple ولا تؤيده Apple.

## قائمة الكلمات

القائمة في [tools/kids-words.txt](tools/kids-words.txt). لتعديلها أضف الكلمة تحت المستوى المناسب، ثم أعد بناء الفهرس:

```powershell
python tools/build_index.py <مجلد فيه text_model.onnx و tokenizer.json>
```

ملفا مُشفّر النصوص من [Xenova/mobileclip_s0](https://huggingface.co/Xenova/mobileclip_s0) ولا يحتاجهما التطبيق نفسه. السكربت يحتاج numpy و onnxruntime و tokenizers.
